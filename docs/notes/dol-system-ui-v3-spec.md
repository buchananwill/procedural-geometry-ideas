# D0L System UI V3 Spec

1. Copy/Paste D0L config as JSON to/from clipboard (matches straight skeleton polygon clipboard tool)
2. Default turtle drawing start should be centered in the canvas.
3. Keywords should be: `F, f, +, -, [, ]` so the "forward" instructions are side-by-side.
4. Make divider between canvas and config panels movable on large displays, so the instructions can be given more space when reading them.
5. Need debug option to turn off provenance gathering
6. `Generate` button should be moved to top of config panels, not in a disclosure
7. raw text `x` in the Alphabet Definitions is jarring - it is somehow unobvious in purpose. `x` and `Add` should both be svg icons for + in a circle, and `-` in a circle. Natural opposites and equal visual weight.
8. Visual production rule builder:
	1. Fiddly to drag a Letter pill to the last position when multi line.
	2. Dragging to the middle line of a multi-line rule seems not to be possible
